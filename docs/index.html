GEM fit is a transparent rule, not a model output: growth board (35), small deal (30), emerging-market exchange (20), capital-hungry sector (15). Unknown inputs score half, and are labelled. Open any row to see the points.

Emails are tiered. VERIFIED = the person's address is published on the company's own site or filing. INFERRED = the company's naming pattern applied to a confirmed name. Otherwise N/A — never a guess: in deal sourcing a wrong address burns the contact.

Sector, description and missing officers are extracted by a model from the linked documents, and kept only if the supporting quote is found verbatim in the source. Those quotes are shown in each row.
